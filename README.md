# Stopwatch Project

A simple stopwatch built using HTML, CSS, and JavaScript.

## Features

- Start timer
- Stop timer
- Reset timer

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

- `start()` → Starts the stopwatch
- `stop()` → Stops the stopwatch
- `reset()` → Resets the stopwatch to `00:00:00:00`
